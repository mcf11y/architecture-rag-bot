# Задание 4. RAG-бот

## Краткое описание

RAG-бот реализован в `scripts/rag_bot.py`. Цепочка собрана **вручную** (не «чёрный ящик» `RetrievalQA`), чтобы было видно, что происходит под капотом:

1. **Запрос** пользователя → эмбеддинг **тем же энкодером**, что и индекс (`BAAI/bge-small-en-v1.5`).
2. **Поиск** ближайших чанков в **ChromaDB** (`vector_store/`), top-k=4, косинусная близость.
3. **Сборка промпта:** system-промпт с **Chain-of-Thought** + **few-shot** примеры + блок контекста с найденными фрагментами (с указанием источников).
4. **LLM** (современная модель 2026): по умолчанию **`claude-sonnet-5`** (можно `claude-opus-4-8` через `--model`).
5. **Ответ** пользователю в формате «Рассуждение → Ответ → Источники», либо честное **«Я не знаю»**.

**Техники промптинга:**
- **Few-shot** — 2 примера в формате «контекст + вопрос → рассуждение + ответ», сформированные из реальных фрагментов базы (`the-synth-flux.md`, `tashiin.md`). Второй пример специально показывает поведение «Я не знаю».
- **Chain-of-Thought** — system-промпт требует сначала пошагово рассуждать, потом давать финальный ответ.
- **Грунтинг + отказ** — модель обязана отвечать только по контексту; плюс мягкий барьер по близости (`MIN_SIM=0.30`) для совсем нерелевантных запросов.

## Запуск

```bash
pip install -r requirements.txt
python scripts/build_index.py --clean        # если индекс ещё не построен

python scripts/rag_bot.py                     # интерактивный REPL
python scripts/rag_bot.py "What is the Synth Flux?"   # одиночный запрос
python scripts/rag_bot.py --demo              # прогон демо-диалогов ниже
```

LLM конфигурируется через окружение: `RAG_LLM_MODEL`, `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` (совместимо с Anthropic Messages API).

## Примеры успешных диалогов (5)

### 1. Что такое Synth Flux и каковы его две стороны?
Найдено: the-synth-flux.md (sim 0.79/0.74/0.67), the-void-reaver.md (0.63)
> **Рассуждение:**
> 1. В [1] дано определение Synth Flux — энергетическое поле, связывающее галактику.
> 2. В [2] названы две стороны: Radiant Current (мир, знание) и Umbral Current (страх, гнев).
>
> **Ответ:** Synth Flux — таинственное энергетическое поле, объединяющее галактику. У него две стороны: **Radiant Current** (мир, знание, сострадание; последователи — Aegis Warden) и **Umbral Current** (страх, гнев, жажда власти; последователи — Void Reaver).
> **Источники:** the-synth-flux.md

### 2. Кто отец Кэла Доунрайдера (Kael Dawnrider)?
Найдено: kael-dawnrider.md (0.70/0.61), anixar-dawnrider.md (0.64), mirefen.md (0.62)
> **Рассуждение:**
> 1. В [4] сказано, что Кэл узнал: Xarn Velgor — его отец, Anixar Dawnrider.
> 2. В [2] подтверждается, что Anixar Dawnrider стал Void Reaver Lord Xarn Velgor.
>
> **Ответ:** Отец Кэла Доунрайдера — **Anixar Dawnrider** (он же Void Reaver Lord Xarn Velgor).
> **Источники:** kael-dawnrider.md, anixar-dawnrider.md

### 3. Какую планету уничтожил Void Core и кто отдал приказ?
Найдено: aldareth.md (0.77), the-void-core.md (0.74/0.73/0.72)
> **Рассуждение:**
> 1. В [1] сказано, что Aldareth уничтожен по приказу Overlord Tarkis с помощью Void Core.
> 2. В [3] это подтверждается.
>
> **Ответ:** Void Core уничтожил планету **Aldareth**, приказ отдал **Overlord Tarkis**.
> **Источники:** aldareth.md, the-void-core.md

### 4. Какое оружие используют Aegis Wardens?
Найдено: the-warden-circle.md (0.69/0.64), the-arc-glaive.md (0.67), oben-karis.md (0.65)
> **Рассуждение:**
> 1. Вопрос об оружии Aegis Wardens.
> 2. В [2] сказано: построение arc glaive — обряд посвящения; обычно синие/зелёные клинки.
>
> **Ответ:** Aegis Wardens используют **arc glaive** — энергетический клинок, цвет которого задаёт кристалл (обычно синий или зелёный).
> **Источники:** the-arc-glaive.md

### 5. Где Кэл Доунрайдер обучался у мастера Vodaan?
Найдено: mirefen.md (0.80), vodaan.md (0.74), kael-dawnrider.md (0.74/0.68)
> **Рассуждение:**
> 1. В [3] сказано, что Kael искал мастера Vodaan на болотном мире Mirefen.
> 2. Подтверждается [1] и [2].
>
> **Ответ:** Kael Dawnrider тренировался с мастером Vodaan на болотном мире **Mirefen**.
> **Источники:** mirefen.md, vodaan.md, kael-dawnrider.md
